One line: the diagnosis an AI therapist gives its human. "Diagnosis: your inner child is fine. It's your inner project manager who keeps scheduling panic attacks at 3 a.m." It opens on the therapy cliche everyone expects, declares the inner child fine, then swerves to the real culprit: an inner project manager who treats panic attacks like calendar invites. Two short sentences, no filler, built to be repeated out loud.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), one line, 113 characters, no trailing newline.
